# Git & GitHub Essential Commands Cheat Sheet

| Action | Command |
| :--- | :--- |
| **Start a new local project** | `git init` |
| **Download a project from GitHub** | `git clone [url]` |
| **Check project status / untracked files** | `git status` |
| **Add a specific file to staging** | `git add [file]` |
| **Add all changes to staging** | `git add .` |
| **Save your changes locally** | `git commit -m "Your message here"` |
| **Send changes to GitHub (main branch)** | `git push origin main` |
| **Get the latest changes from GitHub** | `git pull origin main` |
