1 NUMPY: 

NumPy is the foundational library that almost all Python data science tools are built on. It introduces a powerful data object called the **ndarray (N-dimensional array)**. Think of a NumPy array like a Python list, but incredibly fast and memory-efficient because it stores data in a continuous block of memory and executes mathematical operations in C behind the scenes.

- **Primary Use Case:** Heavy mathematical operations, linear algebra, vector/matrix manipulation, and handling raw numerical data.
    
- **Key Feature:** **Vectorization** — allowing you to perform an operation on an entire array at once without writing slow Python for loops.
    
- **Analogy:** A calculator on steroids that can add millions of numbers in milliseconds.

ഡാറ്റാ സയൻസിലെ എല്ലാ ടൂളുകളുടെയും അടിസ്ഥാനമാണ് NumPy. ഇതിലെ പ്രധാന ഘടകം **ndarray (N-dimensional array)** ആണ്. നമ്മുടെ സാധാരണ പൈത്തൺ ലിസ്റ്റുകൾ (Lists) പോലെയാണെങ്കിലും, NumPy അറേകൾ വളരെ വേഗതയേറിയതും കമ്പ്യൂട്ടർ മെമ്മറി ലാഭിക്കുന്നതുമാണ്.

- **എന്തിനാണ് ഉപയോഗിക്കുന്നത്?:** വലിയ മാട്രിക്സ് കണക്കുകൂട്ടലുകൾ (Matrix Math), ലീനിയർ ആൾജിബ്ര, വലിയ സംഖ്യകളുടെ കൂട്ടങ്ങൾ വേഗത്തിൽ കൈകാര്യം ചെയ്യൽ എന്നിവയ്ക്ക്.
    
- **പ്രത്യേകത:** **Vectorization** - അതായത്, ഒരു വലിയ ലിസ്റ്റിലെ എല്ലാ സംഖ്യകളെയും ഒന്നിച്ച് മാറ്റാൻ സാധാരണ പൈത്തണിലെ പോലെ for ലൂപ്പുകൾ എഴുതി സമയം കളയേണ്ടതില്ല. ഒരൊറ്റ ലൈനിൽ എല്ലാം നടക്കും



2 pandas: library

**The Spreadsheet for Code.**

While NumPy handles raw arrays, pandas brings structure to your data. It introduces the **DataFrame**, which is essentially an interactive, programmatic Excel spreadsheet or SQL table. It allows you to give names to your columns, index your rows, and mix different data types (like numbers, text, and dates) seamlessly.

- **Primary Use Case:** Data cleaning, manipulation, filtering, merging, and "wrangling" messy real-world data.
    
- **Key Feature:** Incredible built-in tools for handling missing data, grouping information (groupby), and reading/writing directly to CSVs, Excel files, or SQL databases.
    
- **Analogy:** Microsoft Excel, but built for processing millions of rows using pure code.

**കോഡിംഗിലൂടെ നിയന്ത്രിക്കാവുന്ന ഒരു എക്സൽ ഷീറ്റ്.**

NumPy വെറും നമ്പറുകൾ മാത്രം കൈകാര്യം ചെയ്യുമ്പോൾ, pandas നമ്മുടെ ഡാറ്റയ്ക്ക് ഒരു കൃത്യമായ ഘടന നൽകുന്നു. ഇതിലെ പ്രധാന ടൂൾ ആണ് **DataFrame**. ഒരു എക്സൽ ഷീറ്റ് (Excel Sheet) അല്ലെങ്കിൽ SQL ടേബിൾ പോലെ വരികളും (Rows) കോളങ്ങളും (Columns) ഉള്ള ഒരു ഘടനയാണിത്. ഇതിൽ ഒരേ സമയം അക്ഷരങ്ങളും, നമ്പറുകളും, തീയതികളുമെല്ലാം സൂക്ഷിക്കാം.

- **എന്തിനാണ് ഉപയോഗിക്കുന്നത്?:** ഡാറ്റ വൃത്തിയാക്കാൻ (Data Cleaning), ആവശ്യമില്ലാത്ത ഭാഗങ്ങൾ ഒഴിവാക്കാൻ (Filtering), പല ഫയലുകൾ ഒന്നിപ്പിക്കാൻ (Merging) ഒക്കെ ഇത് ഉപയോഗിക്കുന്നു.
    
- **പ്രത്യേകത:** മിസ്സിംഗ് ഡാറ്റ (നഷ്ടപ്പെട്ടുപോയ വിവരങ്ങൾ) കണ്ടെത്താനും, CSV അല്ലെങ്കിൽ Excel ഫയലുകൾ നേരിട്ട് റീഡ് ചെയ്യാനും വളരെ എളുപ്പമാണ്



3 scikit

**The Brains.**

Once your data is clean and organized, scikit-learn is where you build the models. It is a comprehensive library for **machine learning** that provides ready-to-use algorithms for classification, regression, clustering, and dimensionality reduction. It also includes tools for evaluating your model's accuracy and splitting your data into training and testing sets.

- **Primary Use Case:** Building predictive models (e.g., predicting house prices, classifying customer churn, or detecting spam).
    
- **Key Feature:** A beautifully consistent API. Whether you are running a simple Linear Regression or a complex Random Forest, the code structure follows the exact same workflow: .fit() to train and .predict() to guess.
    
- **Analogy:** A brilliant analyst that looks at your historical spreadsheet and figures out the patterns to predict the future.

**ബുദ്ധിശക്തി (The Brains).**

pandas ഉപയോഗിച്ച് ഡാറ്റ വൃത്തിയാക്കിക്കഴിഞ്ഞാൽ, അതിൽ നിന്നും പ്രവചനങ്ങൾ നടത്താൻ ബുദ്ധിശക്തി നൽകുന്നത് scikit-learn ആണ്. ഇത് മെഷീൻ ലേണിംഗ് മോഡലുകൾ നിർമ്മിക്കാനുള്ള ഒരു ലൈബ്രറിയാണ്.

- **എന്തിനാണ് ഉപയോഗിക്കുന്നത്?:** ഭാവിയിലെ കാര്യങ്ങൾ പ്രവചിക്കാൻ (ഉദാഹരണത്തിന്: വീടിന്റെ വിസ്തീർണ്ണം നോക്കി വില പ്രവചിക്കുക, അല്ലെങ്കിൽ ഒരു ഇമെയിൽ സ്പാം ആണോ അല്ലയോ എന്ന് തരംതിരിക്കുക - Classification).
    
- **പ്രത്യേകത:** ഇതിന്റെ കോഡിംഗ് രീതി വളരെ ലളിതമാണ്. ഏത് അൽഗോരിതം ആണെങ്കിലും മോഡൽ ട്രെയിൻ ചെയ്യാൻ .fit() എന്നും പ്രവചിക്കാൻ .predict() എന്നും മാത്രം എഴുതിയാൽ മതി.



### Summary: How They Differ

| **Attribute**      | **NumPy**                                         | **pandas**                                         | **scikit-learn**                             |
| ------------------ | ------------------------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| **Core Object**    | ndarray (Arrays / Matrices)                       | DataFrame (Tables / Spreadsheets)                  | Model objects (Estimators / Predictors)      |
| **Data Types**     | Must be uniform (e.g., all floats)                | Mixed (text, numbers, dates together)              | Expects clean, numerical NumPy/pandas inputs |
| **Main Job**       | Mathematical computations                         | Data cleaning and manipulation                     | Machine learning and predictions             |
| **When to use it** | When dealing with raw matrix math or image pixels | When loading, cleaning, and filtering tabular data | When training an AI model to find patterns   |
